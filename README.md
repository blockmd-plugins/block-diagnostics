# 性能与占用 (block-diagnostics)

实时查看 Block 主进程的 CPU、物理内存（RSS）与总磁盘占用，并通过可交互的 7 类面积图（Treemap）定位笔记、资源图片、历史快照、恢复缓存、AI 会话、日志与配置状态的空间分布。

## 功能

- **实时指标**：每秒自动采样 Block 主进程 CPU 与物理内存，并展示总磁盘占用与统计时间。
- **7 类磁盘面积图**：按物理占用（硬链接去重、稀疏文件准确统计）呈现 7 类数据分布，点击或悬停方块即可查看明细与占比。
- **手动刷新**：点击顶栏「刷新」立即重新扫描全部笔记本与应用数据目录。

## 安装方式

1. 打开 **Block** -> **设置** -> **应用商店**，找到「性能与占用」点击**安装**。
2. 或在「手动安装」输入框填入 `blockmd-plugins/block-diagnostics` 安装。
